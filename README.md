# Документы «Точки старта»

PUBLIC_DRAFT_FOR_REVIEW. Публичный проект для ознакомления с текущим состоянием. Содержит незаполненные поля и ещё не утверждён для релиза приложения.

Статический сайт: главная, соглашение, политика и неизменяемые снимки редакций в archive/.
legal-manifest.json содержит SHA-256 канонического текста (UTF-8/LF) отдельно от SHA-256 файлов HTML.
Оформление не меняет юридическую редакцию. Для чтения JavaScript не требуется.

После утверждения текста и состава файлов: Settings → Pages → Deploy from a branch → main → / (root). Используется HTTPS. .nojekyll отключает обработку Jekyll.
Снимки черновиков не являются историей утверждённых документов.
